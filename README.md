# Data Studio

Приложение для сбора, поиска, анализа и правки данных из любого REST API.
Изначально сделано под Data Studio, но к нему не привязано: источники
описываются JSON-файлами, программировать для подключения нового API не нужно.

---

## 🔒 Главное: в API уходят только GET-запросы

Приложение **физически не может** изменить что-либо на стороне API.
Это не договорённость и не обещание, а блокировка в коде.

Модуль `api_guard.py` подменяет точки входа `requests` и `aiohttp`. Любой
вызов с методом, кроме `GET`, `HEAD` и `OPTIONS`, падает с исключением
**до открытия сетевого соединения** — запрос не уходит в сеть вообще.
Под блокировкой находятся и сборщик, и приложение, и запуски по расписанию.

Проверить самому — двойной клик по **`check_readonly.bat`** (или
`python selftest_readonly.py`). Скрипт пытается отправить PUT, POST, PATCH и
DELETE всеми способами, которыми это вообще делается в проекте, и показывает,
что каждый из них заблокирован:

```
✅ session.request(PUT)     ЗАБЛОКИРОВАНО
✅ requests.post()          ЗАБЛОКИРОВАНО
✅ aiohttp PATCH            ЗАБЛОКИРОВАНО
✅ requests.delete()        ЗАБЛОКИРОВАНО
```

Дополнительно ведётся журнал **всех** исходящих запросов — метод, адрес,
HTTP-код, время ответа. Он виден в приложении на вкладке «Журнал API».
То есть режим «только чтение» не только гарантирован заранее, но и
проверяем постфактум.

**Тогда как же «редактирование»?** Правки применяются к вашей локальной копии
data и хранятся отдельным файлом `studio.db`. Список правок выгружается в
CSV/JSON — его можно передать тому, кто вносит изменения в первоисточник.
Подробнее — в разделе «Правка данных».

## Быстрый старт

1. **Посмотреть приложение прямо сейчас**, без токена и без установки
   библиотек: двойной клик по `demo_data.bat`, затем по `studio.bat`.
   Создастся набор выдуманных данных, и приложение откроется в браузере.

2. **Работа с настоящими данными:**
   ```
   pip install -r requirements.txt
   ```
   Затем `studio.bat` → вкладка «Сбор» → вставить токен → «Запустить сбор».

Самому приложению никакие библиотеки не нужны: оно собрано на стандартной
библиотеке Python и работает офлайн. Зависимости из `requirements.txt`
требуются только для похода в API и записи Parquet/Excel. Если их нет,
приложение честно скажет, чего не хватает, и всё равно откроет уже собранные
data.

Не Windows? Те же команды без `.bat`:
`python demo_data.py`, `python studio.py`, `python selftest_readonly.py`.
