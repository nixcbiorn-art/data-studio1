Качество данных

Профиль колонок

Заполненность, уникальность и разброс по каждой колонке. Низкая заполненность у важного поля — повод не доверять расчётам по нему.

Найденные аномалии

Заполненность данных

по полям, по записям и в разрезе групп
Полнота сбора (сколько записей догрузилось) смотрите на вкладке «Проверки». Здесь другое измерение: насколько у самих записей заполнены поля. Общий процент взвешенный — обязательные поля из описания источника весят больше опциональных.

Поля: доля заполненных значений

* — обязательное поле по описанию источника. Зелёный ≥ 90%, жёлтый 50–90%, красный < 50%.

В разрезе групп

Сквозные проверки

сходятся ли таблицы между собой и вся ли информация на месте
Поиск аномалий смотрит на необычное внутри одной таблицы. Здесь другое: проверяется, сходятся ли таблицы друг с другом и не потерялась ли часть данных при сборе. Такие поломки не выглядят странно — просто цифры меньше, чем должны быть, и по ним делают неверные выводы.

Найденные связи между таблицами

Определяются автоматически — по описаниям источников и по именам колонок. Работают и для источников, которые вы добавили сами.

Проверка эндпоинта

HTTP GET — по умолчанию. Через браузер — для сайтов, которым нужен JS, куки или защита от бота. Ждать селектор нужно, если содержимое рисуется скриптом и появляется не сразу.

Загрузка CSV пачками

Свои данные без похода в API. Файл читается в браузере и заливается частями по 1000 строк за запрос, поэтому большие файлы не роняют ни браузер, ни сервер. Результат появляется в списке ниже и на вкладке «Внешние». «Заменить» — старые данные под этим именем удаляются, «Добавить» — новые строки дописываются к уже загруженным.

Подключённые источники

Redcat-источники из папки sources/. Внешние — из sources_external/, они помечены внешний.

Редактор описания

Внешние источники

Источники, которые не относятся к Redcat. Хранятся в отдельной базе reports/external_data.db, не пересекаются с данными Redcat и собираются независимо — командой python redcat_scraper.py --only <ключи> или через вкладку «Сбор» (там они помечены).

Профиль колонок

Сверка с Redcat

Настраивается в spec внешнего источника, секция cross_check: какие поля сопоставлять, какие метрики сравнивать, какая агрегация, пороги классов. Нажмите ⇄ Сверить с Redcat в шапке вкладки.
Отчёт появится здесь: сводка по классам, таблицы расхождений, группы «только слева / только справа».
